The Structure of a URL

URL means Uniform Resource Locator

  1. Protocol is either http:// or https://, and the s is for secure
  2. Host Name is formatted www.domain._/, with either com, org, edu, gov, io, us, au, en, or more.
  3. Path is Optional, is in the format of /folder1/folder2/
  4. File is Optional, index.html is a file name, and is not always shown within the url, and that is a security measure against hackers, and index equates to the home page of a directory

the base Tag defines the base URL for the website, for all files referenced in the HTML document.

If we set the base as img, we would only have to put imageName.jpg to insert an image.

The ling Tag is how we connect to CSS files and external files, not to scripts. It creates a relationship between the current document and an external document. If you are in your index.html and you want to connect it to your styles.css file, you would use link rel="stylesheet" type="text/css" href="css/styles.css" with no closing tag, since link is a standalone tag.
